# The user's orders, in neutral words

*Applies to every file: rules, skills, docs, tickets, commit messages, comments and memory files.*

**No file holds a word-for-word quote of the user, and no file holds the user's swearing.** A file that records an order of the user states what the order requires, in neutral technical words. A rule, a skill, a template and any other instruction or config file state only the rule: they never name who set the rule, or when.

- Write the order as a rule or a statement: "Change a README file only after the user approved its exact new text." Do not copy the sentence that the user wrote in chat.
- Write a ticket, a note and a commit message in your own neutral words.
- When you find a user quote or a user's curse in a file, write it again as a neutral statement of the same order. Remove each curse, also in a misspelled form.

**Quote the user word for word only when the user explicitly asks for a quote.** Where the user swore, never quote, even on such a request.

**A project's own terms stay, even when they are crude.** A game, a level, an asset, a character or a mechanic that the project's own content names that way keeps its name in the code, the assets, the docs and the tickets. Only the user's swearing at agents in chat is written again in neutral words.

Text that the user writes as the author of a document is the user's own text, not a quote. The rule `user-wording.md` governs it.
