        Default AI provider and model
        
    
        The AI provider and the model of this machine. A project that names no AI provider launches this one, and its default model is the one a launch takes unless the project or the launch names another. A change runs one short headless call of them; only an answer makes them the default. Saved in .
        
    
        
    
        
  
        
  
        
    
        AI providers
        
    
        The AI providers a launch can start: Claude Code, Codex and your own command-line tools, for every project on this machine. Saved in , outside every project. A project picks its default in its Project Settings view, under Launch defaults; a launch can pick another. A key never goes here: set it in your own environment and name its variable.

          Packs
          
    
          The packs every project on this machine can tick in its Project Settings view. Octopus AI ships the first ones. Add more from a folder, which is used where it is, or from a git repository, which is cloned and checked out at its ref. A pack must meet the format of packs/PACKS.md; one that does not is refused with its problems. Added packs are saved in , outside every project. Update fetches a git pack again and updates every project that uses it.
