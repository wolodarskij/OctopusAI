
**A project-wide README file is not part of the work.** A `README*` file in the root folder
of a project changes only after the owner approved its exact new text
(`readme-needs-owner-approval.md`). Do the rest of the ticket, then show the owner the new
text and ask. The README guard refuses the write until the approval is recorded. A
`README*` file in any other folder changes as any other file.
