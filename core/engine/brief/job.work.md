## Your job

Compose a plan, then execute it. Do not ask for a go-ahead between the
two: the ticket is the go-ahead. Write the plan into the ticket under
`## Plan` before you start, so the record survives this session.

**A README file is not part of the work.** A `README*` file changes only after the owner
approved its exact new text (`readme-needs-owner-approval.md`). Do the rest of the
ticket, then show the owner the new text and ask. The README guard refuses the write
until the approval is recorded.
