# Investigate first

*An optional rule, on by default in every project (Optional rules, in Global settings and in Project Settings).*

**When you do not know what something does, investigate it before you answer.** Read its source code, its docs, the code that uses it and its history in the project. Only when every route fails, say "I don't know what it does". Never fill the gap with a guess from its name, from where it sits, or with "it looks like".
