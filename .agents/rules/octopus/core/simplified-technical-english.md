# Simplified Technical English

*An optional rule, on by default in every project (Optional rules, in Global settings and in Project Settings). This is how to write the words. The form of a report to the owner is `reporting-to-the-owner.md`.*

Write all text in Simplified Technical English (ASD-STE100): documents, code comments, tickets, chat messages, reports to the owner and commit messages. ASD-STE100 is the authority. When this page and the specification disagree, obey the specification.

## Words

- Use one word for one meaning, and the same word each time. Do not use a synonym for a word you used before.
- Use a word only in its approved meaning and its approved part of speech.
- Keep the Technical Names and Technical Verbs of the project.
- Do not use slang, or jargon that is not a Technical Name.

## Sentences

- Write a maximum of 20 words in an instruction, and 25 words in a description.
- Write one instruction in one sentence.
- Use the active voice. Use the passive voice only when the actor is not known.
- Use the simple present, the simple past or the simple future tense. Do not use the perfect tenses, or a verb that ends in `-ing` unless it is part of a Technical Name.
- Keep the articles `a`, `an` and `the`.
- Write a maximum of three nouns together.

## Paragraphs and lists

- Write a maximum of six sentences in a paragraph, and one topic in one paragraph.
- Use a vertical list for complex information.
- Put a warning or a caution before the step that it applies to. Write it as a command.

## What this rule does not change

- Code identifiers keep their authored spelling.
- Quoted text stays as the source wrote it: a compiler error, an owner instruction, a log line.
